## Setup

1. Fork this project on GitHub.
2. Clone your fork to your computer.
3. In the project folder, create a file named `.env`.
4. Add the following to your `.env` file, replacing the placeholder values with your information:

```text
SENDER_EMAIL=sender-email-here@gmail.com
APP_PASSWORD=xxxx-xxxx-xxxx-xxxx
RECIPIENT_EMAIL=recipient-email-here@gmail.com
```

> **Important:** Do not share or commit your `.env` file to GitHub. It contains your Gmail App Password.

### What is an App Password?

An App Password is a special 16-character password generated by Google that allows the program to securely log in to your Gmail account. It is different from your regular Google account password.

### How to create an App Password

1. Go to [Google Account](https://myaccount.google.com/).
2. Select **Security and Sign-In**.
3. Turn on **2-Step Verification** if you haven't already. Follow Google's instructions to complete the setup.
4. Go to [Google App Passwords](https://myaccount.google.com/apppasswords).
5. Create a name/label for the app or project. The name is only used to help you identify the App Password and does not affect the project.
6. Google will generate a 16-character App Password.
7. Copy the App Password and replace the placeholder in the `.env` file:

```text
APP_PASSWORD=xxxx-xxxx-xxxx-xxxx
```

### Sending an Email

To send an email, replace the `message` variable in `email_bot.py` with your desired message.

Then run the program:

```bash
python email_bot.py
```

Your email will be sent from the Gmail address specified in `SENDER_EMAIL` to the address specified in `RECIPIENT_EMAIL`.
